Projects

Handwritten Digit Identifier

Python, TensorFlow, Keras, CNN, MNIST, Pillow, NumPy, Streamlit

Handwritten Digit Identifier is a deep learning-powered computer vision application that recognizes handwritten digits from 0 to 9. Users can upload an image of a handwritten digit or capture one directly using their device camera. The application processes the image and predicts the digit using a Convolutional Neural Network trained on the MNIST dataset of 70,000 handwritten digit images.

The trained model achieved 98.75% accuracy on the MNIST test dataset, demonstrating its ability to classify handwritten digits with high accuracy.

How it works

The application uses a Convolutional Neural Network (CNN) trained on the MNIST dataset. When a user uploads or captures an image, Pillow and NumPy handle image processing and preprocessing to prepare the input for the model.

The processed image is passed to the trained TensorFlow/Keras model, which analyzes its visual patterns and predicts the most likely digit. Streamlit provides the interactive interface for image uploads, camera input and predictions.

EstateML

Python, Scikit-learn, K-Means, Streamlit

Nigerian property sites show thousands of listings with little personalisation. EstateML asks what you need (bedrooms, bathrooms, toilets, parking and budget) and returns the best-fitting homes in Lagos and Abuja, ranked.

How it works

Data, preprocessing, K-Means clustering, distance scoring, ranked recommendations, then a Streamlit app. Properties are grouped by pattern, and each one is scored by how close it is to what you asked for.

Submitted to the Nigeria Prize for Science and Innovation hackathon with Team De Ekklesia.

Customer Segmentation

Python, pandas, Scikit-learn, PCA, Streamlit

Businesses can’t treat every customer the same. This app sorts 2,627 customers into 4 segments by age, marital status, education, work experience, family size and spending score, and shows a profile for each. Upload your own CSV and choose how many segments you want.

How it works

I filled gaps in the data, encoded the categories, scaled every feature, clustered with K-Means, profiled each segment, and used PCA to plot seven features in two dimensions.

Interactive Image Processing App

Python, Streamlit, Pillow, NumPy

Images are just grids of numbers, and this app lets you see that. Upload a JPG or PNG, check its height, width, colour channels and data type, resize it with sliders anywhere from 50 to 2000 pixels, and download the result in one click.

How it works

Pillow opens the uploaded image and NumPy turns it into an array, so the app can show its exact shape and data type in real time. The width and height sliders resize the picture with Pillow, and Streamlit generates the download of the resized file.
